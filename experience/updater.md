# Updater — Senior IT Solutions Administrator

## Scope

Individual-contributor role in a relatively flat startup organization supporting roughly 250 employees across the United States, with an approximately 80% macOS / 20% Windows endpoint mix. Reported to the Director of IT and served as the service-desk team's point person for KPI goals, queue management, escalation support, and mentoring newer members, without hiring, people management, or performance evaluation. Emphasis on identity, endpoint automation, SaaS administration, Linux support, and service-desk improvement.

## Responsibilities and Accomplishments

- Acted as the service-desk technical lead for KPI goals, queue management, escalation support, and mentoring; did not hire, manage, or evaluate performance.
- Migrated endpoint management from hybrid Active Directory to a cloud-first Microsoft Azure AD and Okta-integrated architecture.
- Eliminated the legacy Windows Active Directory dependency for endpoint management.
- Improved automation and IT service-desk practices through Okta optimization, Freshservice documentation, and automated endpoint deployments.
- Configured and administered Jamf and Microsoft Intune for endpoint management.
- Administered Google Workspace, Slack Enterprise, Microsoft Azure AD, and Freshservice.
- Supported DevOps operations and infrastructure with an emphasis on Linux administration and systems integration.

## Technologies and Practices

Linux, Microsoft Azure AD, Windows Active Directory, Okta, Jamf, Microsoft Intune, Google Workspace, Slack Enterprise, Freshservice, endpoint automation, DevOps support.
