# Genesys — Senior Automation & Platform Engineer

## Scope

Designed and automated enterprise endpoint deployment and management, aligning Windows and Apple management while supporting identity modernization, security policy, and asset visibility.

## Responsibilities and Accomplishments

- Designed and implemented an endpoint deployment and management architecture using Microsoft Intune / Endpoint Manager.
- Aligned the Windows endpoint experience with Jamf capabilities and organizational branding.
- Built application packages, VPN certificate deployments, configuration profiles, and policies aligned with IT service and security requirements.
- Enabled zero-touch device drop shipment from vendor to end user with automated setup and no manual IT interaction.
- Began migrating devices from on-premises Active Directory to Microsoft Azure AD.
- Integrated device inventory with ServiceNow.

Microsoft Intune / Endpoint Manager, Jamf, Microsoft Azure AD, Windows Active Directory, ServiceNow, application packaging, certificate deployment, configuration profiles, policy management, zero-touch deployment.
