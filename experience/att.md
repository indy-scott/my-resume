# AT&T — Senior Advanced Technical Support

## Scope

Provided senior operational support across telecom service platforms, including cloud-hosted network-functions virtualization and clustered UNIX/Solaris systems. Served as a technical lead for Linux, networking, virtualization, performance analysis, maintenance, and upgrades.

## Internal Roles

### Advanced Technical Support Manager — Advanced Intelligent Network / SS7

**September 1999–mid-2012 · Individual-contributor role**

- Supported the Advanced Intelligent Network (AIN) systems underlying the Midwest SS7 telecommunications network.
- Supported 14 Alcatel-Lucent eCS Service Control Point systems across eight central-office locations in the Chicago metropolitan area.
- Those systems supported telecommunications traffic across Wisconsin, Illinois, Indiana, Michigan, and Ohio.
- Installed, configured, maintained, and troubleshot Alcatel-Lucent eCS Service Control Point (SCP) systems.
- Administered the eCS platform on Solaris x86 with vendor-developed high-availability clustering software.
- Monitored the environment through Lucent's 5ESS switching alarm and monitoring system and routed alarms and notifications to external collection and reporting systems.
- Developed KornShell scripts to rapidly collect system metrics, health data, and operating statistics.
- Wrote database-health scripts used to assess and tune the Oracle 9i relational database for the eCS platform.
- Reduced routine system-check and maintenance effort by approximately 20–30 minutes each time the scripts were used; they ran daily during the major control-unit upgrade and later supported maintenance and troubleshooting.
- Led the replacement of both control units at each of six production locations while preserving service through high-availability single-node operation.
- Co-led the physical implementation with one other engineer and served as the team's resident TCP/IP networking expert as the network architecture changed substantially during the upgrade.
- Worked within a four-person internal team: two engineers led physical implementation while two managed software and quality-assurance testing.
- Jointly developed the change plan, schedule, test plan, and rollback plan, coordinating with two vendor engineers who supported the project on a rotating schedule.
- Rebuilt each replacement control server from scratch during a full maintenance window, then managed data synchronization that continued for several days before replacing the peer node.
- Completed the six-site rollout over approximately four months while maintaining 99.9999% service availability.
- Executed two planned rollbacks in response to faulty equipment; one unit was replaced, while the other was repaired in-rack by replacing core system components.
- Diagnosed upgrade problems and coordinated the application of vendor hotfixes needed to complete the rollout.
- The higher-capacity control units and newer software enabled consolidation from eight locations to six while increasing supported traffic.
- The added CPU capacity and software capabilities enabled additional telecommunications services that generated millions of dollars in incremental revenue.
- Participated in 24×7 on-call coverage, planned maintenance windows, escalated troubleshooting, and major outage response.
- Handled end-to-end incident responsibilities including technical diagnosis, vendor coordination, change execution, stakeholder communication, service restoration, and post-incident analysis.
- Supported network services including Caller ID, Local Number Portability, call-control functions, and business-grade telecommunications services.

### Senior Advanced Technical Support Manager — Cloud NFV Operations

**Mid-2012–April 2019**

- Performed production operations in a DevOps environment for a cloud-based telecom NFV vendor solution hosted in AT&T's private OpenStack cloud.
- Deployed and maintained NFV solutions using MongoDB, REST APIs, Nagios, and infrastructure as code with Ansible.
- Served as team lead for IP networking, Linux administration, and virtual-machine and hardware performance analysis.
