# Genesys — Senior Automation & Platform Engineer

## Scope

Individual-contributor role supporting internal teams rather than customers. Designed and automated enterprise endpoint deployment and management for a global fleet of just over 3,000 endpoints, approximately 70% macOS and 30% Windows, aligning Windows and Apple management while supporting identity modernization, security policy, asset visibility, and tool-to-tool integrations. Owned the identity-source cutover that made Okta authoritative for Windows AD and Azure AD.

## Responsibilities and Accomplishments

- Served as the sole administrator of the Microsoft Endpoint Manager / Intune platform for just over 3,000 endpoints, approximately 70% macOS and 30% Windows.
- Provided automations and integrations between internal tools used by IT support, database, application support, developer, and security teams.
- Designed and implemented an endpoint deployment and management architecture using Microsoft Intune / Endpoint Manager.
- Owned Intune packaging and Windows deployment configuration using native Intune utilities; there was no separate package-creation platform.
- Wrote PowerShell scripts to support MDM deployment and maintenance, including scripts that converted unmanaged Windows machines into fully Autopilot-capable devices.
- Contributed Windows-side policy settings and governance so the Windows endpoint experience aligned with Jamf capabilities and organizational branding; Jamf packaging and automations were primarily owned by another team member.
- Applied security-team requirements in Intune and Jamf rather than originating the security policy.
- Deployed trusted Wi-Fi connection certificates and remote VPN connection certificates and profiles through Intune and Jamf.
- Enabled zero-touch device drop shipment from vendor to end user with automated setup and no manual IT interaction, covering approximately 10–15 new and replacement devices per month.
- Reduced new-device tickets by roughly 30–40% because Windows and macOS setup and software installs no longer required IT interaction.
- Shortened new-device delivery from about two weeks to a few days, limited mainly by vendor stock.
- Owned the identity-source project from testing through completion: rebuilt Okta, on-premises Windows AD, and Azure AD connections so Okta became the source of truth and both directories consumed a downstream feed covering Windows and macOS endpoints.
- Established a role-based identity workflow that improved security, sped provisioning and deprovisioning, and reduced reliance on a deprecated Windows AD system heading for retirement.
- Completed the device migration of the entire Windows fleet from on-premises Active Directory to Microsoft Azure AD.
- Partnered with the IT support team to test identity changes as they were implemented; Jamf-side identity and packaging work remained with the engineer who owned Jamf.
- Partnered with the ServiceNow engineer to define Microsoft Graph API connections that let ServiceNow pull live Intune inventory into the CMDB, keeping asset data current on the primary ticketing and support platform.

## Technologies and Practices

Microsoft Intune / Endpoint Manager, Microsoft Autopilot, Jamf, Microsoft Azure AD, Windows Active Directory, Okta, Microsoft Graph API, ServiceNow, PowerShell, native Intune application packaging, Wi-Fi certificates, VPN certificates, configuration profiles, policy management, zero-touch deployment, role-based identity.
